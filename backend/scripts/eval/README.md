# Deep Counselor evaluation harness

`python -m scripts.eval_counselor_deep --offline` is the default. It replays the model outputs in `backend/tests/fixtures/deep_personas/*.json` through the real deep-turn, Analyst, Notebook, and memory extraction/reconciliation code on disposable SQLite student workspaces. It blocks provider clients and socket connections, uses a no-op vector index, and writes Markdown and JSON reports to `backend/scripts/results/`. The one-turn recordings exercise integration; they do **not** establish live conversation quality.

Live mode is opt-in and is **not run by this PR**. It requires `--live --max-cost-usd <positive amount>`. The runner creates a disposable student workspace per persona, uses the simulator and grader prompts in this directory, runs the deep turn followed synchronously by the Analyst and memory extraction, and stops at a mirror request or the turn limit. It tracks every model call and writes a partial report if the cost budget is reached. Configure prices for every chosen model before starting; an unpriced model is rejected before its call. The no-op vector index keeps synthetic data out of an external vector store. The harness evaluates Counselor actions but does not execute research delegation or mirror UI jobs.

`model_prices.json` contains editable standard short-context USD rates per million tokens. The long-context adjustment for Astra is data-driven. The initial values were checked against the [Astra](https://developers.openai.com/api/docs/models/gpt-6-astra), [GPT-5 Mini](https://developers.openai.com/api/docs/models/gpt-5-mini), and [GPT-5.4 Mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini) model pages. Check rates before any later live run. Estimates use the provider's reported input, cached input, output, and reasoning token counts; reasoning tokens are included in output, not charged a second time. Provider-specific cache writes and non-model tools are outside this estimate.

The JSON report retains the full per-call usage, transcript, Notebook, and grader result. The Markdown report is for review. Qualitative metrics use the grader's recorded or live output; missing grader judgments are shown as *ungraded* rather than assumed to be zero.
