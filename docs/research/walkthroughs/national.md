# National walkthrough: how admission works in Pakistan

P2 people-lane item H2 (master spec §8.4; P2 spec §6.2). Region: national. Researched and drafted by Claude on 2026-11-07.

**Rules for this file.** Every line cites an official page (HEC `hec.gov.pk`, IBCC `ibcc.edu.pk`, PMDC `pmdc.pk`) with a verbatim quote, the date read and the read method. A line without an official source says so. Nothing here is from memory. The batch 1 v4 workbook was used only as a lead for which pages to open; every quote below was read again on 2026-11-07.

**Read methods.** `curl + HTML text strip`: the page was downloaded and its tags removed; the quote is the visible text with whitespace collapsed. `curl + pdftotext`: the PDF's text layer. Where a PMDC PDF is a scanned page with an OCR text layer, the OCR noise is kept verbatim (for example `600/o` for `60%`, `8l` for `81`); those lines need a person to read the image before any value is relied on. No model read any quote: WebFetch was used once for a lead on the IBCC lists and its answer was not used (its member count was wrong; see §3).

**Check 2 (independent).** A separate script re-downloaded every cited URL into a new folder on 2026-11-07 and searched each quote word for word (whitespace collapsed on both sides). It did not read the draft's statements or any verdict; it only had URL and quote. The list counts were recomputed from the re-downloaded files. Its result is the `check 2` column. Check 1 (owner ruling P2 §11.2: AI checks are enough) is still to be done by a separate pass and is left blank.

Seat categories are not a national matter in what was found: they are set per province and per admitting university, so they belong in the regional walkthroughs. The only national rule found is the MDCAT domicile rule (N-19).
