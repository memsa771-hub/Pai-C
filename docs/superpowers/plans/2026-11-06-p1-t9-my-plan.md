# P1-T9: "My plan" — rename, route pages, always visible, route words, sources on facts, label test — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With the My plan part on, "Study abroad plan" becomes **"My plan"** (R-50). Each route declares its own plan pages, and the menu shows only those (R-51). Menu labels, page titles and pack nouns come from the route's playbook, like step titles already do (R-52). "My plan" is visible from the start, with an empty state before a choice (R-53). Every outside fact on a My plan screen shows its source link, the date checked and its level (R-54). A label test renders all four routes and fails on another route's words, and on "abroad", "visa" or a plane icon on a route that does not leave the country (R-55). With the part off, the app is today's, byte for byte.

**Architecture:**
- **OS side.**
  - The playbook schema gains two optional top-level blocks:
    - `pages:` (key, label, title, optional noun);
    - `sources:` (the checked date of each citation source ID).
  - The Germany playbook and the three fake playbooks declare them.
  - `plan_view.v1` fills its existing `pages` codes from the pinned playbook.
  - A new port, `ports/my_plan.py`, carries the host's `enabled()` gate.
  - A new endpoint, `GET /v1/os/plan`, returns the student's plan state, route, pages and a `sources` map (url → date checked). It answers 404 while the gate is off.
- **Host side.**
  - `backend/app/pai_os_bridge.py` gains `my_plan_enabled()`, which is `part_on("CONNECT_MY_PLAN")`.
  - `app/main.py` passes it to `mount_os`.
- **Frontend.**
  - A `MyPlanProvider` in `CounselorShell` fetches `GET /v1/os/plan` once per workspace. It gives `{on, plan}` to the rail group, the OS header, the command menu, the Journey plan card, the Vault strip, the OS pages and the roadmap.
  - `on: false` (404, an error, still loading, outside the provider) renders today's UI.

**Tech Stack:** Python 3.13, SQLAlchemy Core (OS), FastAPI, Pydantic v2, Next.js, vitest/testing-library, pytest.

**Spec:** `docs/superpowers/specs/2026-11-04-p1-connection-core-design.md` §3.8, P1-D9, P1-D12, §5 T9, §7 item 8. Master: R-50–R-55, §11, §4 (ownership), §8.2 (levels), §10 (frozen files).
- **Code map:** the session scratchpad `p1-t9-explore.md`. All file:line references below come from it, checked on `pc/p1-t9-my-plan` (on top of T6, `410784c`).
- **Controller decisions:** D-z1…D-z16 below. There is no separate rulings file: this plan's controller took them within the spec.
