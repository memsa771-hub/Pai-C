# P0 Setup Implementation Plan (P0-T1 baseline green, Task 0 setup)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `pai-connect` green and give it the guard rails every later phase relies on: traceability, the freeze check, the missing CI jobs, CODEOWNERS and the new `CLAUDE.md` rules.

**Architecture:** Two stdlib-plus-PyYAML scripts at the repo root (`scripts/check_traceability.py`, `scripts/check_freeze.py`) with pure functions tested from `backend/tests/` (so the existing `legacy` job runs them). CI gains `frontend`, `standalone` and `traceability` jobs in `ci.yml` and a separate `freeze.yml`. The requirement list lives in `docs/requirements/connection.yaml`.

**Tech Stack:** Python 3.12 (CI) / 3.13 (local), pytest, PyYAML 6.0.3, GitHub Actions, Node 22, vitest, TypeScript 5.9.

**Spec:** `docs/superpowers/specs/2026-11-03-p0-setup-design.md`, master `docs/superpowers/specs/2026-11-03-pai-connect-design.md`.

## Global Constraints

- Branches: cut from `pai-connect`; P0-T1 on `pc/p0-t1-baseline`, Task 0 on `pc/p0-t0-setup`; squash-merged; P0-T1 merges first.
- Never weaken a test to make it pass; fix the cause (master §0.6). If a fix needs a test change, the PR says why.
- No Pakistani or other country names in `app/os/**/*.py` (R-58). Test files and data are exempt.
- Do not edit frozen Counsellor paths (master §10) in P0-T1 or Task 0.
- Backend tests run from `backend/` with `env -u PAI_API_KEY python -m pytest -q -p no:cacheprovider`.
- OS tests need Postgres: `OS_TEST_DATABASE_URL=postgresql://os_test:os_test@localhost:5432/os_test`.
- Commit messages end with the session attribution lines; no model names in commits or files.
- Tag new tests `@pytest.mark.req("R-xx")` (or module `pytestmark`).

## Review Focus

1. **Renamed or deleted frozen file.** A PR that moves `deep/analysis.py` must still be caught: diff with `--no-renames` so both paths appear (Task 0.3 test `test_rename_out_of_frozen_dir_is_caught`).
2. **Exception label without an R-ID.** `freeze-exception` alone must still fail (Task 0.3 `test_label_without_rid_fails`).
3. **A setting moved, not changed.** Reordering `config.py` must not trip the freeze; changing `PAI_COUNSELOR_MODEL`'s default must (Task 0.3 `test_reorder_is_not_a_change`, `test_counsellor_model_default_change_is_caught`).
4. **Tag typo.** `req("R-7")` or `req("R-99")` must fail the traceability check, not pass silently (Task 0.2 `test_unknown_or_malformed_rid_is_reported`).
5. **Standalone job selecting nothing.** If the marker is lost, `-m standalone` must fail, not pass with 0 tests (Task 0.4 `test_standalone_marker_selects_gate_tests`).
