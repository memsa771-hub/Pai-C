# P2-T4: reading what is hard to read: render fallback, ScanText, Urdu normalisation, not_readable — Implementation Plan

Branch `pc/p2-t4-reading` (cut from `pc/p2-t3-sources`). Spec: P2 §4.3, §6.1 row T4, P2-D12, P2-D13, P2-D14, P2-D19 not needed.
R-IDs: R-74 (render fallback), R-29 (OCR, Urdu), R-72 (marking), D-15 (quotes stay in the original language).

## Constraints
- Flags off = byte-identical: no renderer and no scanner given to `PageGateway` means today's behaviour; Latin text normalises as before.
- No paid OCR calls. No model calls. Fixtures are fictional and built from text inside the tests (PIL, reportlab, pypdfium2).
- Docling is not installed here and is not forced: its adapter is written against the documented API, unverified, tests skipped when absent.
  Tesseract is not installed: its adapter is tested against a fake `tesseract` executable (plumbing only) and a real-binary test that skips.
- No country names in code. Urdu folding is data (`normalise.yaml`).
- Migration `os_0027_reading` chains on T3's `os_0026` (this branch is cut from T3; the controller renumbers at merge).

## Files
- `alembic/versions_os/os_0027_reading.py`; `app/os/models.py`: `os_pages.read_method/language` (cache keeps how a page was read), table `os_not_readable`.
- `app/os/settings.py`: `render_shell_max_chars`, `render_timeout_s`, `scan_min_pdf_chars`, `scan_max_pages` (additive).
- `knowledge/research/normalise.yaml` + `text.py` (`normalise` applies it; `detect_language`).
- `knowledge/research/render.py`: `PlaywrightRenderer` (browser has no network; every request is served through the gateway's httpx client under the allow-list), `looks_like_js_shell`.
- `knowledge/research/scan.py`: `ScanText` port, `ScanResult`, `ScanFailed`, `FixedScanText` (fake), `TesseractScanText`, `DoclingScanText`, `rasterise_pdf`.
- `knowledge/research/readability.py`: `NotReadableStore` (mark/open/resolve), `is_not_readable(blocked)`, `machine_status_ceiling(read_method)`.
- `knowledge/research/pages.py`: optional `renderer=`, `scanner=`; `Page.read_method/language`; render for shells, OCR for images and image-only PDFs; failures become `not_readable:<how>`.
- `knowledge/research/run.py`: store step marks not_readable sources and fields, caps OCR-read facts at `unconfirmed`, records `read_method`/`language` on facts.
- `knowledge/research/bakeoff.py` + `scripts/scan_bakeoff.py`: scores adapters on fixtures (quote match, similarity, time).
- Tests: `test_p2_normalise.py`, `test_p2_render.py`, `test_p2_scan.py`, `test_p2_not_readable.py`, `test_p2_bakeoff.py`, `scan_fixtures.py` helper.
