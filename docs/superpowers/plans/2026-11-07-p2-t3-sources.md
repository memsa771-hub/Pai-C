# P2-T3: sources: allow-lists, integrity checks, suspect flow, page snapshots, spam proof — Implementation Plan

Branch `pc/p2-t3-sources` (cut from `pc/p2-t1-foundations`). Spec: P2 §4.2, §6.1 row T3, decisions P2-D10, P2-D11.
R-IDs built: R-24 (official sources only), R-71 (spam/hijack integrity, preferred suffix), R-29 (snapshot part).

## Global constraints
- No country names in `app/os` code; allow-list data is YAML (R-58). The committed `lists/` directory holds no real
  entries (nothing from memory): reviewed lists arrive from the people lane (H3). Tests use fictional `.test` data.
- Flag off = byte-identical: `PageGateway(...)` without a `sources=` guard behaves exactly as today.
- Retries only as DBOS step retries (invariant 7): no retry code here.
- No model or API calls.

## Files
- `alembic/versions_os/os_0028_sources.py`: `os_source_domains`, `os_page_snapshots`, `os_source_files` (down_revision `os_0027`; renumbered from os_0026).
- `app/os/models.py`: three Table definitions (additive).

- `app/os/knowledge/sources/suspect.py`: `SourceGuard` (what the gateway calls) and `drop_domain_facts`.
- `app/os/knowledge/research/pages.py`: optional `sources` guard, `fetch(..., scope=None)`, TLS failure recorded, `Page.snapshot_id`.
- `app/os/runner/worker.py`: build the guard when `OS_SOURCE_GUARD=1` (off by default).
- Tests: `tests/os/test_p2_sources_migration.py`, `test_p2_sources_allowlist.py`, `test_p2_sources_integrity.py`,
  `test_p2_sources_snapshots.py`, `test_p2_sources_gateway.py` (incl. spam fixture proof), data fixtures under `tests/os/fixtures/`.

## Tasks (tests first)
1. Migration and models; migration up/down test.
2. Allow-list loader, store, preferred suffix, reactivate (two-person, approver check injected; T5 supplies `os_reviewers`).
3. Integrity checks as pure functions over text/links/previous snapshot; thresholds from YAML.
4. Snapshot store (hash dedupe, original bytes for PDFs/images, size cap).
5. Gateway integration: suspect/not_official lookup before cache, integrity after read, snapshot per read page, TLS failure -> suspect.
6. Suspect flow: facts of the domain drop to `unconfirmed` via `set_status` (cause `monitor`), `after_fact_change` hook, review hook
   (T5 owns `os_review_items`; here an `os_events` row `source_suspect` and an injectable callback).
7. Spam proof with `fixture_sites` (`beta-college.test/admissions`): refused, domain `suspect`, facts dropped, later fetch refused.
8. Checks (full tests/os, legacy, tach, freeze, heads, traceability) and report.
