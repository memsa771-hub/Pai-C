# P2-T8 plan: intakes and the yearly rollover (R-26, R-61, R-62, R-63, R-64, R-65)

Spec: P2 §4.8, row T8; decisions P2-D5, D23, D24, D25; T1 leftovers D-t1-1 (term backfill) and `fallback_previous`.
Branch `pc/p2-t8-intakes`, cut from `pc/p2-t1-foundations`. Migration `os_0026_intakes` on `os_0025`.

## Decisions made here
- **Intake rows are generic.** `os_intakes(region, family, term, year, state, gate_passed_at, opened_from)`; the T1 spec
  keys them by region and family. `current` needs `gate_passed_at` (DB check); only T9's gate sets it (R-66).
- **Slots are rows, their state is derived.** `os_fact_slots` holds only the expected keys `(scope, ref, field,
  owner_ref)` of an intake. "Filled" is read from `os_knowledge_facts` (no second copy to keep in step).
- **Fallback is data driven.** `Service.compile` asks the port for `fallback_previous=True` only when an `os_intakes`
  row for the plan's (term, year) is `open` and none is `current`. No rows (every test and deployment today) = the
  old behaviour, byte for byte.
- **A fact of another year is never firm in the compiler.** `fact.confirmed and fact.intake_year == plan year`.
  Otherwise provisional, with a confirm step; the anchor citation carries the fact's year (R-26).
- **Terms come from `intakes/terms.yaml`**, plus any term a playbook declares (R-62).
- **Backfill (D-t1-1)** is a function and a script mode, not a migration: for rows with `intake_term = ''`, the term is the
  one term in the route's playbook `intake_terms`; routes with zero or several terms are reported, never guessed.
- **Backfill takes the union of terms** across all playbook versions of a route. A route that ever offered two terms is
  `several_terms` and is not backfilled (no guess). Every updated fact gets a `backfill` revision (D-t1-1, `os.rollover`);
  `intake_term` is therefore tracked in revision snapshots, and `backfill` is an allowed cause (migration os_0026).
- **The fallback reads one earlier year.** The newest earlier year at the port (T1's rule). `PlanService` narrows it with
  `fallback_year`: the year of the intake this one was opened from when that is set, else the asked year minus one.
  Several open regions of one (term, year): the newest of their source years.
- **R-63 lives in `PlanService.start_plan`** (`IntakeNotOpen`, an `IntakeError`) for a *new* plan; a plan that already
  exists is still returned, so retries stay idempotent. The builder keeps its own earlier check (`NotAllowed`, 422).
  The Counsellor adapter maps the refusal to `route_not_supported` (no new refusal code, no schema change).
- **`upgrade(version=X)`** refuses a version whose `applies_to` does not cover the plan's intake (R-65).
